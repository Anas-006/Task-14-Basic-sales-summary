Task 14 – Basic Sales Summary

Project Overview

This project focuses on creating a basic sales summary using the Superstore dataset.

Objective

To calculate and summarize basic sales KPIs using Excel formulas.

KPIs Created

- Total Sales
- Average Sales
- Transaction Count

Tools Used

- Microsoft Excel
- Superstore Dataset

Approach

The Sales column from the dataset was used to calculate the three KPIs. SUM was used for Total Sales, AVERAGE was used for Average Sales, and COUNT was used for Transaction Count.

The calculated values were manually verified to ensure accuracy.

Outcome

A simple Summary sheet was created to provide a quick overview of sales performance.

Rollback

Rollback evidence is included to show the original and completed versions of the workbook.
